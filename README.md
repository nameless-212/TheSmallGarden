# 小花园

> 一座用一百年谎言砌成的城市之外，一个被谎言养大的年轻人和一个被城市放逐的疯子园丁，用觉醒的植物对抗死者的潮水。

架空长篇（植物大战僵尸向），共 **27 章、约 13–16 万字**，每章 4000–6000 字，全书时间跨度约 100 天。主题：共生与守护、真相的权利、从被保护到保护他人。

## 创作规范（摘要）

- 所有命名、数字、规则以创作圣经为准；不得自行发明设定。
- 每完成一章，必须回写创作圣经的「第十九节·进度与文件」与「第十八节·伏笔追踪总表」。
- 生命粒子统一用「曦粒子」（学术名 α-维生粒子），严禁使用已废弃的「翠粒子」；凋亡粒子为「烬粒子」。
- 僵尸不是病毒、不是进化，而是烬粒子对尸骸的「附体活化」。
- 平时只写 md 正文；仅在明确要求「改 HTML」时同步 `index.html`。
